## Instructions générales
Veuillez lire toutes les instructions attentivement avant de commencer.

## Règles & Environnement
- Version PowerShell : 5.1+ ou PowerShell Core 7+. Indiquez la version utilisée.
- Vous pouvez utiliser l'éditeur de texte ou l'IDE de votre choix.
- Tous les appels API ciblent l'URL de base fournie dans chaque exercice. L'API ne nécessite aucune authentification.
- Soumettez vos fichiers `.ps1` et tous les fichiers de sortie générés. Nommez les fichiers exactement comme spécifié.
- Pour l'exercice 4, soumettez votre diagramme en PNG, PDF ou utilisez un outil de diagramme (draw.io, Mermaid, Excalidraw, etc.).
- Vous pouvez utiliser des outils IA, de la documentation ou des recherches web. Lors du débriefing, soyez prêt à expliquer votre raisonnement et à parcourir votre code ligne par ligne

## Ce que nous évaluons
- Correction et gestion des erreurs : est-ce que ça fonctionne ? est-ce que ça échoue proprement ?
- Lisibilité du code : nommage, structure, commentaires utiles (pas excessifs).
- Attention aux détails : avez-vous lu les instructions en entier, y compris les cas limites ?
- Approche de résolution : comment vous décomposez un problème, pas si vous avez mémorisé la syntaxe.
- Compréhension des interactions : frontend, backend, scripts, CI/CD — comment tout s'articule.
